# Features

What is configured, and which tag gates it. Anything without a tag is on for every host.

## Desktop -- `desktop`

Umbriel, with [noctalia](https://github.com/noctalia-dev/noctalia) for the bar, launcher, lock screen and control center. Login is the noctalia greeter, defaulting into the Umbriel session.

The Umbriel config is TOML at `modules/user-level/desktop/umbriel/config.toml`. It `[include]`s `noctalia.toml`, generated by noctalia's umbriel template, so colours follow the active palette and are never set directly. X11 apps run on Xwayland with Umbriel's own XWM, which Umbriel spawns itself when `[general] xwayland` is true.

### Workspaces

All five are persistent, each with its own layout.

| #   | Name  | Layout                        | Holds                              |
| --- | ----- | ----------------------------- | ---------------------------------- |
| 1   | COMMS | dwindle                       | vesktop, Steam chat, gajim         |
| 2   | DEV   | scrolling                     | zed                                |
| 3   | WEB   | dwindle                       | helium                             |
| 4   | GAMES | scrolling, full width, no gap | steam, gamescope, ES-DE, Median XL |
| 5   | MEDIA | scrolling, full width         | mpv, Jellyfin                      |

COMMS and WEB inherit the `[layout]` default; the other three are `[[workspace]]` overrides. Umbriel has no master or monocle layout -- a full-width scrolling column stands in for monocle.

The scratchpad holds things you summon and dismiss: `Super+grave` toggles it, `Super+Shift+grave` moves the focused window in or pulls it back out. Transient windows float instead, via `[[window_rule]]` matches on the `--title` the menu launches them with.

## Security

| Thing    | Detail                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| YubiKey  | `pam_u2f` on every PAM service (login, greetd via login, sudo, su, polkit-1, ...). `sufficient`, so the password still works. A touch is enough, except sudo, which also asks for the key's PIN |
| Firewall | nftables, default deny, ping blocked. `tailscale0` and `lo` trusted. The `lab` modules give `virbr0` and `virbr-k8s` DHCP/DNS only             |
| Suricata | `server`. Inline IPS in NFQ mode -- it drops packets, not just alerts. Logs to `/var/log/suricata/`                                            |
| DNSCrypt | `server`. `dnscrypt-proxy`, Cloudflare + Quad9, DNSSEC required, no-log servers required. `systemd-resolved` and `unbound` are both off        |
| AdGuard  | `server`. AdGuard Home owns :53, filters, and forwards upstream to DNSCrypt on 127.0.0.1:5300                                                  |
| Secrets  | agenix with post-quantum age recipients, identity is the host's age key on `/persist`. See [Secrets](./secrets.md)                            |

Open ports:

| Port                             | For                                  |
| -------------------------------- | ------------------------------------ |
| 2222/tcp                         | SSH, opened by sshd itself           |
| 8096/tcp                         | Jellyfin (`server`)                  |
| 51413/tcp+udp                    | Transmission (`server`)              |
| 23243-23262/tcp, 23243+23253/udp | Divinity: Original Sin 2 (`gaming`)  |
| 4000/tcp                         | Median XL Sigma LAN host (`gaming`)  |
| 41641/udp                        | Tailscale (WireGuard)                |

Each module opens its own ports. There is no shared firewall file.

Kernel hardening, in `modules/system-level/boot.nix`: full ASLR (`randomize_va_space=2`), kernel pointers hidden (`kptr_restrict=2`), `dmesg` restricted to root, ptrace limited to descendants (`yama.ptrace_scope=1`), core dumps not kept on disk (systemd coredump `Storage=none`, so a crash still gets a journal entry and backtrace) with `suid_dumpable=0`, SYN cookies, RFC1337 TIME_WAIT protection, ICMP redirects rejected in both directions, and reverse-path filtering. `boot.nix` also sets forwarding off, but the Tailscale exit node in `net.nix` turns it back on for both IP versions. BBR congestion control with the `fq` qdisc is a throughput choice rather than a hardening one.

Boot is `systemd-boot`, keeping 10 generations.

## Development -- `dev`

- zed, the primary editor, gated by `desktop` with the rest of `user-level/desktop/`. It resolves language servers off `PATH`, so its own module ships `nixd`, the formatters and the css/html/ts servers. Config in `modules/user-level/desktop/zed/`.
- devshell: `nix-shell devshell.nix`, or `cd` in and let direnv load it. Drops into the wrapped nushell with nixd, nil, nixfmt, nufmt, basedpyright, ruff, marksman, biome, dprint, clippy, rust-analyzer, rustfmt, typescript-language-server, vscode-langservers-extracted, nvfetcher, pciutils and git.
- toolchains: rust (cargo, rustc, clippy, rustfmt, rust-analyzer), python (python3, uv, ruff), node (nodejs, typescript).
- Claude Code, `ccl` launches `claude-launcher` which picks a project first.
- nix-search-tv, `ns` for fzf-driven package search.
- nix-index + nix-index-database, the command-not-found handler on a pre-built community database.
- [nix-shop](https://codeberg.org/weegs710/nix-shop), `shop`, for running any version of any package without installing it. Wired in `modules/system-level/shop.nix`.
- wireshark, tmux, direnv with `nix-direnv`, gh, hyperfine, jq, ripgrep.

## Gaming -- `gaming`

- steam, the `weegsware` wrapped build, with Proton, gamescope, controller support and 32-bit compat.
- heroic for Epic/GOG, globally wired through gamescope at the host's `mySystem.display` size and refresh rate (2560x1440 @ 144 on HX99G), wayland backend. Its install and prefix paths come from `mySystem.paths.games`.
- Millennium, the Steam skin framework, with the Material-Theme skin recolored by noctalia's `steam` template. It is built from an open upstream PR that adds 64-bit client support, vendored in `weegsware/_millennium.nix`. Steam always starts in desktop mode (`-nobigpicture`).
- MangoHud, with five presets in `presets.conf` from off to a full GPU/CPU/VRAM/frametime readout.
- gamemode, nix-ld, ntsync, protontricks, ProtonUp-Qt, OpenRA.
- ES-DE with RetroArch carrying 31 libretro cores, plus MAME with a flattened `crt-geom` shader chain. Per-core `.opt` files are declarative, in `modules/user-level/gaming/es-de/opts/`.
- Native ports and recomps, each with its own module and declarative config: [Dusklight](https://github.com/TwilitRealm/dusklight) (Twilight Princess), [2Ship2Harkinian](https://github.com/HarbourMasters/2ship2harkinian) (Majora's Mask), [zelda3](https://github.com/snesrev/zelda3) (A Link to the Past), Dinosaur Planet, AM2R, DCSS, Median XL via `d2launcher`, and Godot.

The whole `modules/user-level/gaming/` subtree is gated by one `only.imports` line in its `bundle.nix`.

## Media

Audio is Pipewire + WirePlumber with rtkit, ALSA and pulse bridges, 32-bit ALSA support, and a resampler at quality 10 pinned to 44.1/48kHz. Bluetooth carries LDAC, AAC, aptX HD, aptX and SBC-XQ, with hardware volume on and mSBC off. It is on for `desktop` and `gaming`.

Music is MPD with the rmpc TUI, `desktop`. rmpc's visualizer listens to `mySystem.audio.monitorSource` when a host sets one. Three nushell tools sit alongside it, also `desktop`: `snag` (playlist to MP3), `yoink` (video downloads) and `sync-music` (ADB sync to Android).

Media creation, `desktop`: GIMP 3 with plugins, Inkscape, `gpu-screen-recorder` with a replay buffer, mpv, zathura, qview.

### Media Server -- `server`

`modules/system-level/media-server/` is gated as a subtree:

- Jellyfin with VAAPI hardware decode, on 8096. `/mnt/media/music` is a read-only bind of `~/Music` off `/persist`, because a 700 home directory blocks it otherwise.
- The arr suite: Radarr, Sonarr, Prowlarr, Bazarr, FlareSolverr, Recyclarr on a weekly schedule. All `openFirewall = false`; they are reachable over Tailscale, not the LAN.
- Transmission as a system service with the tremc TUI, RPC bound to localhost only.
- Navidrome, listening on all interfaces so it is reachable over Tailscale.

SearXNG is also `server`-gated, on 8888, fronted by `tailscale serve` over HTTPS.

## Lab -- `lab`

`modules/system-level/k8s.nix` and `k8s-HA.nix`, behind the `mySystem.k8sLab` option tree. Outside `options.nix`, the only other `mySystem` option trees are this one and `mySystem.win11Vm` in `win11-vm.nix`.

## Everywhere

Untagged, because they are true of every machine:

- Tailscale, with its auth key from agenix, and its interface trusted by the firewall
- SSH on 2222
- the firewall and YubiKey
- preservation and the tmpfs root, see [ZFS and snapshots](./zfs.md)
- sanoid snapshots
- nushell as the shell, with the whole def library, launched from bash
- git and jj config, fastfetch, and the TUI tools (btop, pulsemixer, timg, libqalculate)
- the Nix substituters -- `anomalos.cachix.org` and `cache.nixos.org` -- declared fleet-wide in `core.nix` so a new host gets them without being told
- automatic GC daily at 90 days, store optimisation nightly, and a 5GB/15GB `min-free`/`max-free` band
